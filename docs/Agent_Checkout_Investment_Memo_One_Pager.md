# Agent Checkout — Investment Memo (One-Pager)

**Agent-native Shopify commerce on Somnia**

---

## The Opportunity

Commerce is shifting from human browsers to autonomous AI agents. Analysts project a multi-trillion-dollar agent economy by 2030. Meanwhile, 12,000+ MCP servers expose tools to agents, and HTTP 402 (x402) is processing millions of machine-to-machine payments — yet millions of Shopify merchants have no standard way to accept agent orders.

## What We Are Building

A plug-and-play layer that makes any Shopify store **agent-ready in ~2 minutes**. AI agents discover products via MCP, checkout via HTTP 402, settle in native **STT on Somnia**, and receive confirmed Shopify orders — powered by **Somnia Agents** for pricing, validation, and natural-language search.

## Unique Selling Point

The **first unified stack** combining:

1. Shopify merchant onboarding  
2. MCP agent discovery  
3. HTTP 402 micropayments  
4. Somnia Agents (oracle + validation + NL search)  

Competitors solve fragments; we ship the full loop from "find product" to "paid Shopify order."

## Why It Matters

- **Merchants:** new distribution channel without replatforming  
- **Agents:** standardized, verifiable checkout vs. web scraping  
- **Somnia:** flagship commerce use case for STT + Agents + sub-cent fees  

## Traction

Working open-source prototype: merchant UI, dual MCP servers, on-chain STT verification (Shannon Testnet), Supabase, Shopify order sync.

## Next Steps

Encode Agentathon submission → mainnet pilot → Shopify App → agent marketplace.
